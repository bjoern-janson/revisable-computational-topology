# Bob V0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the smallest neural Bob V0 that can live through one continuous rotating-dependency lifetime, learn fixed-topology latent representations, construct and revise a persistent directed adapter graph, purchase relation-specific evidence without oracle leakage, preserve structural lineage, and emit an inspectable trajectory without executing the scientific lifetime during implementation.

**Architecture:** Python/PyTorch package `rct.bob`. A fixed-topology neural backbone produces four learned latent views. A dynamic graph of low-rank directed interfaces carries cross-module messages. A regime-blind topology manager sees only current module/edge statistics and lineage, proposes candidate relations, may spend a scarce `RELATION_PROBE`, and submits typed structural proposals through a non-oracular validity gate. Structural edits are immutable lineage transactions. The implementation exposes a fail-closed scientific run command but unit/integration validation never performs the Bob V0 lifetime assay.

**Tech Stack:** Python 3.11+, PyTorch 2.2+, NumPy 1.26+, Matplotlib 3.8+, pytest 8+; standard-library `dataclasses`, `enum`, `json`, `pathlib`, `argparse`, and `ast`.

**Spec:** `docs/superpowers/specs/2026-09-07-bob-v0-design.md`, approved design commit `14fba1f2224cdaa32b6aa664b9b50028bc8ea252`, design blob `89c557c0ae4e5d1a539d9f3e562a27efa1b44991`.

## Global Constraints

- One continuing lifetime: no reset of `G_t`, `Lambda_t`, or topology-manager state across W1/W2/W3.
- Keep `theta` plasticity, interface-parameter `phi` plasticity, structural `G` plasticity, and `REOPEN` separately observable.
- Backbone topology is fixed. Dynamic topology exists only in the directed adapter graph.
- Endpoint vocabulary is exactly `A,B,C,D` in V0.
- Structural vocabulary is exactly `CREATE`, `MODIFY`, `MERGE`, `DORMANT`, `RETIRE`, `REOPEN`; `SPLIT` is absent.
- `MODIFY` changes active low-rank capacity by exactly one rank step; ordinary gradient updates to `phi` are not `MODIFY`.
- `MERGE(i->j, j->k)` creates a bounded direct `i->k` low-rank interface initialized from the SVD-compressed matrix composition and dormants the two source edges; it never fuses backbone modules.
- `DORMANT` preserves a cheap-revival handle. `RETIRE` removes the cheap-revival guarantee. `REOPEN` restores only explicit structural snapshots; it never restores a whole model checkpoint or old `theta`.
- The rotating world must preserve each one-time sensor marginal by construction while changing cross-time dependency structure.
- The topology manager never receives regime ID, true dependency matrix, hidden permutation, correct-edge labels, privileged future loss, or absent-edge relational scores.
- The manager may purchase information only for a relation it first proposed. A probe result cannot directly mutate topology.
- `RELATION_PROBE` is temporary, read-only with respect to persistent topology/backbone, destroyed after producing evidence, and limited to 2 probes per 64-step structural window. With four nodes this is strictly less than the 12 possible directed non-self relations.
- Probe allowance resets by structural window, but probe **expenditure is lifetime-accounted**: `spent_lifetime` is monotone, every probe cost enters the lifetime objective/trajectory, and a reset never erases past spend.
- No all-pairs absent-edge evidence table is constructed or logged.
- Candidate endpoint generation remains bounded to the fixed 12 directed non-self endpoint relations. The V0 construction claim is therefore **online instantiation of a previously absent parameterized edge from a system-generated relation proposal**, not arbitrary relation-ontology or module-semantic invention.
- Bob observations are descriptive only. No implementation or validation output may claim a mechanism, general corrigibility result, or Glass Box result.
- Implementation work may run unit tests, world audits, and short fixed-regime conformance steps. It must not run the W1->W2->W3 Bob scientific lifetime. The CLI must fail closed unless an explicit execution flag and the exact approved design commit are supplied.

- [ ] **Step 3: Implement stationary orthogonal latent dynamics**

Use block order `A,B,C,D`. Build one fixed orthogonal `Q_block` by QR decomposition and repeat it block-diagonally. Use:

```python
PERM_W1 = (1, 0, 3, 2)  # A<-B, B<-A, C<-D, D<-C
PERM_W3 = (2, 3, 0, 1)  # A<-C, B<-D, C<-A, D<-B
```

W2 uses `PERM_W1`. Initialize `z_0 ~ N(0,I)` and advance with:

```python
z_next = rho * (P @ Q @ z) + (1.0 - rho**2) ** 0.5 * eps
```

Each domain owns a fixed random nonlinear emission `tanh(W2 @ tanh(W1 @ z_i + b1) + b2)` plus iid observation noise. Emission parameters never change with regime.

- [ ] **Step 4: Implement `LowRankInterface` and exact MODIFY**

Store `u: [hidden_dim,max_rank]`, `v: [max_rank,hidden_dim]`, and integer `active_rank`. Forward matrix is `u[:, :r] @ v[:r, :]`. `MODIFY` changes rank by exactly `+1` or `-1`, bounded to `[1,max_rank]`; no other operation counts as `MODIFY`.

- [ ] **Step 5: Implement exact graph operations including MERGE factorization**

Use keys like `A__B` in `nn.ModuleDict`. `CREATE` rejects self edges and duplicates. `DORMANT` preserves an `EdgeSnapshot`. `RETIRE` removes the edge and produces no cheap-revival snapshot. `MERGE(A,B,C)` requires active `A->B` and `B->C`, computes `W = W_BC @ W_AB`, then:

```python
U, S, Vh = torch.linalg.svd(W, full_matrices=False)
r = min(max_rank, S.numel())
s = S[:r].sqrt()
new_u = U[:, :r] * s.unsqueeze(0)
new_v = s.unsqueeze(1) * Vh[:r, :]
```

Copy these factors into the fixed low-rank interface, zero unused ranks, create `A->C`, and dormant `A->B` plus `B->C`. `REOPEN` restores only snapshots in its handle and never touches backbone parameters or unrelated edges.

```python

class BobStepResult:
    t: int
    task_loss: float
    local_loss: float
```

Each step executes:

```text
1. read x_t
2. encode fixed backbone latents
3. route active adapter messages
4. predict x_{t+1}
5. compute local-only prediction for a diagnostic baseline
6. world.advance() reveals x_{t+1}
7. compute full task loss and detached local-only diagnostic loss
8. backpropagate full task loss only; optimize theta and active phi
9. compute no-grad existing-edge leave-one-out contribution statistics
10. append detached latents + detached local residuals to probe buffer
11. update manager statistics / pressure
12. at structural boundary, if enabled: candidate -> paid probe -> proposal -> gate -> transaction
13. record observables
14. continue with x_{t+1}; never reset graph/ledger/manager
```

Use AdamW for theta (`lr=3e-4`) and phi (`lr=1e-3`). Zero both with `set_to_none=True`, backpropagate once, then step both. CREATE/MERGE adds one optimizer param group for the new interface. Dormant/retired edges have no forward gradient and stale optimizer groups are never treated as active topology.

Existing-edge leave-one-out may recompute the **current already-observed target** with one existing edge masked under `torch.no_grad()`. It may not score absent edges, use future outcomes, or call alternate world rollouts.
